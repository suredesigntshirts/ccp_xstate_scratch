Five designs for one factory

Four designers worked independently on the same question: what should pass between states so the work is provably done? A fifth lane built the design we settled on in the six-round challenge, as a control. Each design was then built and tested by a helper, and a blind judge reran every test.

Naming trap: lane A is the minimalist designer. The challenge's “option A” is lane E, the control.

Everyone passed all 12, so size decided it

The headline score is scenarios passed divided by the number of primitives a design needs. Interpreter changes count double. Since every lane passed 12 of 12, the score only measures how few building blocks each design used.

The helper prompt, your special focus

Does the verifier grade the right commit?

The riskiest instruction we give an agent is “check out the PR head, then judge it”. If the verifier forgets, an honest verdict is graded against the wrong commit. The lanes split on whether the host does this step itself.

What it means

Reading the result

What the run showed

  • The control we converged on came last. Six rounds of challenge added observer events and effects, and fresh designers didn't need them.
  • The winner is today's engine with pieces taken out, not a new architecture. Fewest primitives does not mean a smaller chart. Lane A writes 52 transitions in quick-fix, compared with 27 today.
  • The best safety idea came from lane C: the host places the subject the verifier grades. The winner doesn't have it.
  • Lane D tried a genuinely different shape, a fact board. It gave by far the smallest workflow files but needed three interpreter changes.

What it didn't prove

  • No real agent ran against any prompt. All agent output in the tests was stubbed, and GitHub was faked.
  • Lane A's lead rests partly on deletions with real costs. With no timers, a silent worker hangs with nobody told, and a replan tap without a written reason is refused.
  • The scoring rules decide a lot. Counting interpreter changes double is what sank lane D.
  • The recommended combination, lane A plus lane C's host-placed subject, hasn't been built yet.
